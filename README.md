# Cadastro de Interesse - Laboratório de Inovação Digital UnDF

## Sobre o Projeto
Este é um formulário web acessível e responsivo desenvolvido para a disciplina de PBL. O objetivo é permitir que estudantes se inscrevam na lista de espera dos projetos de pesquisa e extensão em menos de 2 minutos, garantindo a proteção de dados em computadores compartilhados.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica e atributos ARIA para leitores de tela.
* **CSS3:** Estilização responsiva, suporte nativo a Dark Mode e variáveis de design.
* **JavaScript (Vanilla):** Lógica de validação em tempo real, manipulação do DOM e proteção de dados via `sessionStorage` sem uso de bibliotecas externas (como jQuery ou React), garantindo máxima leveza.

## Como Executar
O projeto não possui dependências complexas ou necessidade de servidores locais para a interface básica.
1. Baixe os arquivos do projeto.
2. Extraia em uma pasta.
3. Dê um duplo clique no arquivo `index.html`. Ele abrirá automaticamente no seu navegador padrão.
